## CBUG-0048 mixed giant attacks

A Rogue dismisses a storm giant's lightning attacks after treating its boulder
as blocked. In the open-path trial the original stays and loses54 HP; the
correction uses one Phase Door scroll, moves behind a wall and retains130 HP.
With a mold in the path it spends the scroll but still loses54 HP, versus59 HP
without a scroll originally. This is not guaranteed escape or uniform safety.
Three complete primary control logs are unchanged. Independent path-only and
combined diagnostics expose a separate caster-blocking defect; that source
correction is not included here.

Source [issue64](https://github.com/diegoami/neo-angband-tracker/issues/64),
C source `b223c4f18622883549682f9f997b76fe1f06fc73` against pristine C
`e473720ed88a0f0c7ca66815cef3000eb4a38bc3`.
