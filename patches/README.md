canonical finding issue/record and local PR. A stored patch is not applied.

receipts; those are distinct from a C-source patch here. Historical copies in

## CBUG-0004 cold-bite protection

Source [issue26](https://github.com/diegoami/neo-angband-tracker/issues/26),
C source `d504eb3d272ce96c0de2c00eba757a251b551334` against pristine C
`e473720ed88a0f0c7ca66815cef3000eb4a38bc3`.
[Stored patch](upstream-c/CBUG-0004-cold-melee-resistance.patch) and
[readable choice/consequence comparison, replay and Verification](../docs/audit/c-reports/CBUG-0004/README.md).
With only acid protection, the original stays beside a cold-biting troll and
loses21 HP; the correction teleports for2 mana and avoids that scheduled attack.
The inverse cold-only case saves2 mana by staying but takes20 HP; do not present
it as uniformly safer. Four controls are unchanged. This stored C proposal is
not source adoption or an engine/consumer correction.
