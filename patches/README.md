## CBUG-0065 unused Enlightenment potion

stairs beyond a wall remain unknown. The correction drinks one potion and
the native game reveals those stairs. Five complete control logs are unchanged,
including town rejection, unknown/unrelated potions and Augmentation use.

is measured, and one potion is consumed for the information.
