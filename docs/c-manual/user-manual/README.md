# Official user manual (copy)

These files are the reStructuredText source of the official Angband manual,
<https://angband.readthedocs.io/en/latest/>, and the in-game help files from
`lib/help/`, copied unchanged from angband/angband `e473720ed` (the
`c-borg-reference` branch). They let you read the manual for this game
version together with the [strategy manual](../README.md). The text belongs to
the Angband developers; its licence is in [copying.rst](copying.rst).

`thanks.rst`, the list of Angband's contributors, is not copied here. This
repository's private-information scan (`tools/private-scan.mjs`) rejects some
of the names it contains. Read it in the official manual
(<https://angband.readthedocs.io/en/latest/thanks.html>) or in this repository's
pristine upstream copy, [`reference/docs/thanks.rst`](../../../reference/docs/thanks.rst).
