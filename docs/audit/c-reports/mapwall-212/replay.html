New walls and doors never left the Borg's flow

When a grid changes between map passes — a door closes, a tunnel is dug, a wall appears — the Borg is supposed to drop that grid from its routing flows, refresh what it knows, recalculate its view and light, and reset the wizard-light and detect-walls stamps. But the map pass read the grid's "old" wall state after it had already overwritten the grid with the new feature, so old and new always matched and the whole change block was dead: stale flows through freshly closed doors survived, and the Borg kept routing through walls. The correction reads the old state before the overwrite.

What the controls establish

With no feature change between the passes, nothing is invalidated in either version and the logs match byte for byte — the correction changes only the changed-grid cases.

Experiment conditions and limits

Native Human Warrior, depth 30, glowing constructed arena, one watched grid two grids east of the Borg. Between the two production map passes the fixture sets the game feature (a door closes, or opens). Flow, knowledge, icky flags and the stamps are planted before the second pass in the state a flow routine and a stone-to-mud detection would have left — recorded as a fixture intervention. The tracked state after the pass is read back; no movement or survival claim.
