What the control establishes

A parse that is never freed never reaches the free path: both variants evaluate 42 with byte-identical logs - and even the free path's functional output is byte-identical; only the leak report changes.

Experiment conditions and limits

Native calculation machinery only (no game state needed): parse the constant formula "1 + 2", evaluate it (3), and free the calculations as a reinitialize does; the leak proof is the same parse-and-free built with AddressSanitizer and run under LeakSanitizer. The lost allocation is 80 bytes per freed calculation - a bounded leak per reinitialize, not a crash; no death or survival claim. The operator-block leak visible in the same report is the separate lead in issue 324 and remains in both variants.
