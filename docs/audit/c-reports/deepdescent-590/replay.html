Recorded native C runs, original and corrected source

About to die, the Borg read Deep Descent, which takes effect turns later

When the Borg is about to die it runs down a list of escapes. One entry falls back to Deep Descent when no Teleport Level is carried, and the list treats that as a successful flight. But Deep Descent only acts after 3+1d4 player turns and then drops the player below the deepest level reached. So the Borg spent its last turn without moving, and the escapes after it in the list (retries, Teleport Level by spell, Phase Door) were never tried. The correction keeps Deep Descent only for the one caller that wants a delayed dive (starving on level 1).

Original: the Borg reads Deep Descent and counts it as fled. Corrected: Deep Descent is skipped and the escapes after it in the list are tried.
