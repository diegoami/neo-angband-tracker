A fire vulnerability did not cancel the Borg fire resistance

In the game a vulnerability (for example from the burning up curse) takes away one level of the matching permanent resistance, so resistance plus vulnerability leaves none. The Borg noted the vulnerability only to lower the value of its gear; its resistance trait stayed set, so it kept dividing that element damage by three. The correction clears the resistance when a vulnerability cancels it.

The game computes no fire resistance (level 0). Original: the Borg still believes it resists fire and divides the breath by three. Corrected: it agrees with the game.
