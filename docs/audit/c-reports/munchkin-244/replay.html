Recorded native munchkin-mode decisions

The Borg pressed a stair key while standing on floor

In munchkin mode the adjacent-monster scan reuses the pointer to the Borgs own grid for each neighbour, so when the scan ends the pointer sits on the last neighbour examined. The take-the-stair tests that follow read that neighbours feature: a young Borg that remembers a staircase one diagonal step away queues the take-stair key while standing on plain floor. In the game that keypress fails without taking a turn, so the Borg can repeat the same decision indefinitely.

What the control establishes

Standing on a real down staircase, both versions queue the take-stair key and the complete log is byte-identical before and after: legitimate stair-taking is handled before the scan and is untouched by the correction.

Experiment conditions and limits

Native Human Warrior level 1, depth 30, seed 1000, lit constructed arena, birth equipment only, munchkin mode enabled in the Borg configuration (a supported option, off in the stock configuration) with the dispatch gate it requires (max character level under 12). One seen stair is sealed inside a permanent-wall pocket so every stair flow fails and the decision reaches the take-the-stair tests; a remembered-but-untracked down stair sits on the north-west neighbour, the grid the scan examines last. This isolates the stale-pointer test, not full autonomous play; no stuck-in-a-loop claim is measured, only the phantom keypress it starts from. No death or survival claim.
