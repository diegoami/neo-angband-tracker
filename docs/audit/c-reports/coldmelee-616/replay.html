Recorded native C runs, original and corrected source

Cold blows were weighed against temporary acid resistance

The Borg divides the damage of a monster blow by three for each resistance to its element. For cold blows it tested temporary acid resistance instead of temporary cold resistance (a copy slip; the acid, electricity and fire blows above it test their own element). So it overrated cold blows while it resisted cold, and underrated them while it resisted only acid. The correction tests temporary cold resistance.

The game reduces cold damage (resistance level 1). Original: the danger equals the no-resistance reference. Corrected: lower.

Experiment conditions and limits
Native Human Warrior, seed 616, character level 30, dungeon level 28, lit arena, an awake frost giant (two 5d8 cold blows, immune to cold) next to the Borg, the shipped borg.txt. Each run reads the production borg_danger() twice: the reference with no temporary resistance, then with the mode temporary resistance (cold, acid, or fire in the control). Fixture interventions: the timed resistances are set directly; the giant enters the Borg monster list through the production observe_kill_diff().
