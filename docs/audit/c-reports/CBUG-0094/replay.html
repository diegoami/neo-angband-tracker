      What the comparison establishes

      The two affected situations have one extra cast in the original version, costing 20 mana. The correction casts only the selected spell. The other seven situations keep the same behavior.

      Important limit: a second regeneration cast extends its duration. This test does not show that the extra cast is always harmful, nor does it demonstrate a death or a worse fight. It establishes that the Borg casts an extra spell it did not select and pays for it.

      How these results were captured

      A synthetic test gives a Druid the relevant book, learned spells, full health and enough mana. The real Borg preparation code chooses and requests the spells. The test decodes those requests and executes the corresponding native game commands. The game computes the mana cost and spell effects. No monsters or world turns run between these commands, so casts are counted here; extra enemy attacks are not.

      This is a replay of recorded command results, not a live game or an invented combat animation. Health is displayed from the native setup; the fixture has no damaging attack. Regeneration duration increases in the duplicate-cast case.
