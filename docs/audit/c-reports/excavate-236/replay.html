The excavated vault grid was remembered as glowing

When the Borg digs a vault wall with stone to mud, it updates its map of the dug grid: clear the glow flag, then set the flag the comment calls "Dark". The original set the glow flag again instead of the dark flag — the freshly dug grid was remembered as glowing, and glow-driven decisions could treat a dark excavation pocket as safe light. The correction sets the dark flag.

What the controls establish

With no dig site beside a permanent wall, the routine finds nothing in either version and the logs match byte for byte, so the correction changes only the excavation case.

Experiment conditions and limits

Native Human Druid level 12, depth 30, seed 1000, glowing constructed arena, the Gifts of Nature book carried, Turn Stone to Mud learned, full mana. The vault flag is set directly and a quartz grid is planted beside a permanent wall (recorded fixture intervention) — the state a vault wall run would present. The production excavation routine runs directly; the cast keys are shown, not executed. This isolates the flag marking, not full autonomous play.
