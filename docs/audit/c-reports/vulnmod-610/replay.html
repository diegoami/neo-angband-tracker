The Borg did not model an unresisted elemental vulnerability

In the game a vulnerability (for example from the burning up curse) with no permanent resistance to that element sets the resistance level to -1, and adjust_dam() then multiplies the damage by 4/3; temporary resistance only brings the level back to 0. The Borg never multiplied for a vulnerability and still divided by three for temporary resistance, so it underrated fire, cold, electricity and acid attacks. The correction records the unresisted vulnerability and applies x4/3 (or no reduction with temporary resistance) in the melee, breath, ball, bolt and beam cases of borg_danger(). It builds on the #594 correction, where a vulnerability cancels a permanent resistance.

The game takes fire damage x4/3 (level -1). Original: the Borg rates the danger exactly like the no-resistance reference. Corrected: it rates it higher.

Experiment conditions and limits
Native Human Warrior, seed 610, character level 35, dungeon level 35, lit arena, an awake young red dragon three grids away. Worn: a Soft Leather Armour and a Leather Shield whose fire resistance levels the fixture sets for each reading, and the temporary fire resistance timer. Each run reads the production borg_danger() twice: the reference with no fire resistance, no vulnerability and no temporary resistance (game level 0), then the mode configuration. Fixture interventions: the items are made directly; all runes known; the dragon enters the Borg monster list through the production observe_kill_diff().
