The secret-door search never left its own grid

When a bored Borg runs out of things to explore it looks for grids next to walls, where a secret door might be found, and walks to the best one. To compare candidate grids it measures how far each is from where it stands. That measurement was asked to stop early, and because it starts at the Borg's own grid at distance 0 it stopped before measuring any other grid. So the search could only ever pick the grid the Borg already stood on: from the middle of a room it never moved, and next to a wall it searched there and then kept picking the same grid. The correction measures the whole neighbourhood, and the Borg walks to the next wall grid.

Original: three calls, each returns false with no key; the Borg never moves. Corrected: the first call flows toward a wall grid at distance 10 and queues a step (key 51, south-east).

Experiment conditions and limits

Native Human Warrior, seed 146, level 20, depth 5, alone in a closed granite room with no stairs or monsters; the Borg has just arrived on the level. The production borg_flow_spastic(true) (the bored call) runs three times in a row from the same position, as the Borg would call it each turn, and the first queued key is read back after each call. Main room 22x22; the control uses a full-size 196x64 room in which every wall is farther than the level-20 search range (25), so neither version has a candidate. This isolates the search choice; it does not run until a secret door is found.
