Recorded native Maim Foe scores

Maim Foe reported the last monster it looked at

The Maim Foe attack scan tracks the best adjacent target and its score. The simulation pass reports that best score, but the real execution pass — the one that actually aims and casts — returned the loop variable holding the last monster it happened to examine. With two adjacent monsters where the dangerous one is examined first, the cast went to the right target while the reported score belonged to the trivial one. The correction returns the tracked best score.

What the controls establish

With only the lich, last and best are the same monster and both versions report the same score; with nothing adjacent, both report nothing. Those complete logs match byte for byte, so the correction changes only the two-monster case.

Experiment conditions and limits

Native Human Blackguard level 30, depth 30, seed 1000, glowing constructed arena, the Fear and Torment book carried, Maim Foe learned (two blows at this level). The chooser's real-path entry point is called directly with the target list the attack chooser would have filled (recorded as a fixture intervention); the cast keys are queued, not executed. The chooser currently discards this real-path value, so the measured wrongness is in the reported score itself, not in a different cast today.
