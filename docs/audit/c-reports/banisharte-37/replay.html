The Borg never banished evil monsters with the artifact that does it

The Banishment defence can activate the Great Axe of Eönwë, which banishes evil monsters, but only while the Borg has more than 100 hit points. The test read borg.has[BI_CURHP]; borg.has[] is indexed by object kind, so this counts how many of some unrelated object kind the Borg carries and is almost always zero. The artifact route was therefore never taken. The correction tests borg.trait[BI_CURHP].

A level-35 Warrior with 431 hit points wields the Great Axe of Eönwë, whose activation banishes evil monsters, and three awake cave trolls stand next to it (danger 138). The production defence routine chooses a defence. Original: the artifact test reads an unrelated object-kind count, is false, and the Banishment defence is not available; the Borg quaffs a Potion of Berserk Strength (value 5). Corrected: the Borg activates the axe and banishes the three trolls (value 138).
