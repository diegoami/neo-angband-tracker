Recorded native C runs, original and corrected source

A hurt Borg retreated through a grid next to a faster monster

When a monster makes its current grid too dangerous, the Borg looks for a strategic retreat: a safer grid in view and a short path to it. For the first step it means to skip any grid next to a monster faster than itself, because that monster will hit it as it lands. The check found such a monster but only left the monster scan, so the step was taken anyway. The correction skips that route.

A cave spider, faster than the Borg, waits in an alcove beside the first step east. Original: the Borg retreats east through that grid anyway. Corrected: that route is skipped.
