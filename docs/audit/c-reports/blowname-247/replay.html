Recorded native lookups

Unknown blow names walked into the table's NULL end entry

The Borg maps monster blow names (from the game data) to its own danger categories through a small table that ends with a NULL marker. The lookup loop visited that marker too, so a blow name absent from the table reached strcmp against NULL and crashed the Borg — a name a modded blow_effects.txt can supply. The correction stops the loop before the marker; unknown names return NONE and the in-table names keep resolving.

What the recorded run establishes

Experiment conditions and limits
