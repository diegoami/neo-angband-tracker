Recorded native C runs, original and corrected source

With only teleport scrolls, the Borg destroyed the area instead of teleporting

Before casting Destruction (or Teleport Level) in a dangerous fight, the Borg asks whether a plain teleport would land somewhere safe, and if so it teleports instead. That landing check returned at once unless the Borg had both a teleport scroll or spell and a teleport staff. So a Borg carrying only Teleportation scrolls (or only a staff) never ran the check and used Destruction, wiping out the area and everything on its floor, even when a safe landing existed. The correction runs the check with either kind of teleport.

Original: the landing check is skipped (no teleport staff), so the Borg uses its Staff of *Destruction*. Corrected: the check runs, finds a safe landing, and the Borg does not destroy the area.
