Recorded native name matching, defense choice and actual potion use

The Borg mistakes visible Itangast for an unseen “It”

A Warrior already sees and tracks Itangast the Fire Drake. When the name is passed to the Borg's message-matching routine, the original treats its first two letters as the unseen-monster pronoun “It”. Its defense chooser then drinks one True Seeing potion. After the correction, it recognizes Itangast and keeps both potions.

The same checks still request detection for a genuinely invisible ghost. This experiment measures one unnecessary potion consumed in response to an already visible dragon; no extra enemy attack, player injury or death is demonstrated.

Why the correction works

The original compares only the first two letters with It. The correction requires the complete word, while ignoring case. Itangast continues to ordinary named-monster matching; native It, it and Something still request detection. All four complete control logs are identical before and after.

Experiment conditions and limits

Native Human Warrior level 40, depth 52, seed 1000, lit arena, known True Seeing potions, a worn Ring of Flames and temporary fire protection. The dragon is visible and already tracked. The protected character's actual Borg danger estimate is 488, below the unchanged detection gate of 842. An initial unprotected experiment reached 2000 and did not request detection; the false name match does not always spend a potion.

The fixture uses the native game-generated monster name, calls the real production name matcher, then calls the full production defense chooser with its actual danger estimate. It validates the queued item and invokes native potion use, which consumes it and grants timed sight of invisible monsters. No replacement action or effect is supplied.

This isolates named-message assimilation and defense. It does not run the full message parser, an actual monster attack, the entire caution/attack decision loop, world turns or a whole fight. No player-harm, encounter-frequency or overall survival claim. The extra sight could help against a later unseen monster; that future benefit was not tested.
